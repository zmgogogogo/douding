## 一、服务器环境

### 1.1 安装依赖

```bash
# Java 17 JDK
sudo dnf install -y java-17-openjdk-devel

# MySQL 8.0
sudo dnf install -y mysql-server
sudo systemctl start mysqld && sudo systemctl enable mysqld

# Redis
sudo dnf install -y redis
sudo systemctl start redis && sudo systemctl enable redis

# Nginx（通常已预装）
sudo dnf install -y nginx
sudo systemctl start nginx && sudo systemctl enable nginx

# Maven 3.6（系统自带版本足够，pom.xml 已做兼容处理）
sudo dnf install -y maven
```

### 1.2 切换 Java 17 为默认

```bash
sudo alternatives --set java java-17-openjdk.x86_64
sudo alternatives --set javac java-17-openjdk.x86_64
```

**JAVA_HOME 路径：** `/usr/lib/jvm/java-17-openjdk-17.0.19.0.10-1.0.2.1.al8.x86_64`

> 注意：若版本号有变化，用 `ls /usr/lib/jvm/` 查看实际路径。

### 1.3 关键路径

| 用途 | 路径 |
|------|------|
| 应用源码 | `/home/admin/server-java/` |
| JAR 文件 | `/home/admin/server-java/target/douding-server-1.0.0-SNAPSHOT.jar` |
| 前端静态文件 | `/var/www/douding/` |
| 应用日志 | `/home/admin/server-java/logs/` |
| Nginx 配置 | `/etc/nginx/conf.d/douding.conf` |
| Systemd 服务 | `/etc/systemd/system/douding.service` |

## 二、数据库

### 2.1 创建数据库

```bash
mysql -u root -e 'CREATE DATABASE IF NOT EXISTS douding CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;'
```

### 2.2 清空重建（仅开发/初始化）

```bash
mysql -u root -e 'DROP DATABASE IF EXISTS douding; CREATE DATABASE douding CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;'
```

### 2.3 MySQL 连接配置

生产环境配置在 `application-prod.yml` 中，通过 systemd 环境变量注入：

```
DB_URL=jdbc:mysql://localhost:3306/douding?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
DB_USERNAME=root
DB_PASSWORD=
```

## 三、迁移脚本兼容性（重要！）

> **MySQL 严格模式不允许 TEXT / JSON 列有默认值。** 编写新迁移时注意：

```sql
-- ❌ 错误（MySQL 不兼容）
description TEXT DEFAULT '',
permissions JSON DEFAULT '[]',

-- ✅ 正确
description TEXT,
permissions JSON,
```

现有 `pom.xml` 已做 Maven 3.6.2 兼容性覆盖：

```xml
<properties>
    <!-- 兼容服务器 Maven 3.6.2（Spring Boot 3.3.2 默认要求 3.6.3+） -->
    <maven-compiler-plugin.version>3.10.1</maven-compiler-plugin.version>
    <maven-jar-plugin.version>3.3.0</maven-jar-plugin.version>
    <maven-resources-plugin.version>3.3.1</maven-resources-plugin.version>
    <maven-surefire-plugin.version>3.1.2</maven-surefire-plugin.version>
</properties>
```

生产配置覆盖 Flyway 使用 MySQL 迁移脚本（而非 H2）：

```yaml
spring:
  flyway:
    locations: classpath:db/migration    # MySQL 版本
    # 开发环境用 classpath:db/migration-h2
```

## 四、部署流程

### 4.1 完整部署（本地 → 服务器）

```bash
# 0. 本地提交代码
git add -A && git commit -m "release" && git push

# 1. 上传 server-java 源码
rsync -avz --exclude 'data/' --exclude 'target/' \
  ./server-java/ admin@47.109.29.158:/home/admin/server-java/

# 2. 构建前端（如前端有改动）
npm run build

# 3. 上传前端
rsync -avz ./dist/ admin@47.109.29.158:/var/www/douding/

# 4. 构建 JAR（在服务器上）
ssh admin@47.109.29.158 "JAVA_HOME=/usr/lib/jvm/java-17-openjdk-17.0.19.0.10-1.0.2.1.al8.x86_64 /usr/bin/mvn -f /home/admin/server-java/pom.xml package -DskipTests -q"

# 5. 重新部署（清库 + 重启）
ssh admin@47.109.29.158 "
  mysql -u root -e 'DROP DATABASE IF EXISTS douding; CREATE DATABASE douding CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;'
  sudo systemctl restart douding
"
```

### 4.2 快速重新部署（仅代码更新）

```bash
# 上传源码 → 构建JAR → 重启
rsync -avz --exclude 'data/' --exclude 'target/' ./server-java/ admin@47.109.29.158:/home/admin/server-java/
ssh admin@47.109.29.158 "
  sudo systemctl stop douding
  rm -f /home/admin/server-java/target/douding-server-1.0.0-SNAPSHOT.jar
  JAVA_HOME=/usr/lib/jvm/java-17-openjdk-17.0.19.0.10-1.0.2.1.al8.x86_64 /usr/bin/mvn -f /home/admin/server-java/pom.xml package -DskipTests -q
  sudo systemctl start douding
"
```

> ⚠️ **注意**：如果迁移脚本有改动，需要在步骤中加入 `DROP DATABASE` 清库重建。

### 4.3 仅更新前端

```bash
npm run build
rsync -avz ./dist/ admin@47.109.29.158:/var/www/douding/
```

前端更新无需重启后端，Nginx 直接 serve 静态文件。

### 4.4 仅更新配置

```bash
scp deploy/douding.service admin@47.109.29.158:/tmp/
ssh admin@47.109.29.158 "sudo mv /tmp/douding.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl restart douding"
```

## 六、Nginx 配置

配置文件：`/etc/nginx/conf.d/douding.conf`

```nginx
upstream douding_backend {
    server 127.0.0.1:8080;
    keepalive 32;
}

server {
    server_name douding.online www.douding.online 47.109.29.158;
    client_max_body_size 50M;
    root /var/www/douding;
    index index.html;

    # API 代理到 Spring Boot
    location /api/ {
        proxy_pass http://douding_backend;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }

    # WebSocket 协作
    location /ws/ {
        proxy_pass http://douding_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 上传文件
    location /uploads/ {
        alias /var/www/douding/uploads/;
    }

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    listen 443 ssl;
    ssl_certificate /etc/letsencrypt/live/douding.online/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/douding.online/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
}

server {
    if ($host = www.douding.online) { return 301 https://$host$request_uri; }
    if ($host = douding.online) { return 301 https://$host$request_uri; }
    listen 80;
    server_name douding.online www.douding.online 47.109.29.158;
    return 404;
}
```

更新配置：

```bash
scp deploy/douding-nginx.conf admin@47.109.29.158:/tmp/
ssh admin@47.109.29.158 "sudo cp /tmp/douding-nginx.conf /etc/nginx/conf.d/douding.conf && sudo nginx -t && sudo systemctl reload nginx"
```

## 七、Systemd 服务配置

文件：`deploy/douding.service`（项目仓库中）

```ini
[Unit]
Description=豆丁 Douding Spring Boot 后端服务
After=network.target mysql.service redis.service
Wants=mysql.service redis.service

[Service]
Type=simple
User=admin
WorkingDirectory=/home/admin/server-java

Environment=JAVA_HOME=/usr/lib/jvm/java-17-openjdk-17.0.19.0.10-1.0.2.1.al8.x86_64
Environment=SPRING_PROFILES_ACTIVE=prod
Environment=DB_URL=jdbc:mysql://localhost:3306/douding?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
Environment=DB_USERNAME=root
Environment=DB_PASSWORD=
Environment=REDIS_HOST=localhost
Environment=REDIS_PORT=6379
Environment=REDIS_PASSWORD=
Environment=JWT_SECRET=douding-jwt-secret-change-me-in-production
Environment=JWT_ADMIN_SECRET=douding-admin-jwt-secret-change-me
Environment=PORT=8080

ExecStart=/usr/lib/jvm/java-17-openjdk-17.0.19.0.10-1.0.2.1.al8.x86_64/bin/java -jar /home/admin/server-java/target/douding-server-1.0.0-SNAPSHOT.jar
ExecStop=/bin/kill -15 $MAINPID

Restart=always
RestartSec=10

StandardOutput=append:/home/admin/server-java/logs/stdout.log
StandardError=append:/home/admin/server-java/logs/stderr.log

[Install]
WantedBy=multi-user.target
```

## 八、故障排查

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| Maven 报不支持发行版本 17 | 系统默认 Java 是 11 | 设置 `JAVA_HOME` 指向 Java 17 |
| `TEXT can't have a default value` | MySQL 严格模式 | 移除 TEXT/JSON 列的 DEFAULT |
| Flyway `Validate failed` | 迁移校验失败 | 清空数据库重建让 Flyway 重跑 |
| 端口 8080 不监听 | 应用启动失败 | `journalctl -u douding -n 50` 看日志 |
| JAR 只读无法覆盖 | 服务正在运行 | 先 `systemctl stop douding` 再构建 |
| 图片转换返回 422 | Spring 提前消费了 multipart 流 | 确保 `resolve-lazily: true` |

### 日志排查

```bash
# 启动错误
tail -100 /home/admin/server-java/logs/stdout.log | grep -E "Caused|Error|Exception"

# 系统服务日志
sudo journalctl -u douding --no-pager -n 50

# 排查迁移问题
mysql -u root douding -e "SELECT * FROM flyway_schema_history;"
```
