拼豆首页・纯作品专区瀑布流开发详细文档
一、整体需求梳理
1.1 业务限定
首页仅展示用户上传拼豆作品，剔除模板、教程、活动卡片；
作品分类 Tab：最热、推荐、我的 三标签横向切换；
最热：全平台作品，综合点赞 + 收藏加权分值排序
推荐：个性化智能推荐，依据用户历史点赞、收藏、收藏作品标签 / 名称相似度做内容分发
我的：当前登录用户本人发布的全部作品
1.2 整体页面结构
plaintext
页面顶层导航
├─ 顶部搜索栏
├─ 作品Tab栏（最热 / 推荐 / 我的，横向切换、滚动吸顶）
└─ 核心区域：作品瀑布流（等宽不等高JS精准Masonry布局）
   ├─ 骨架屏（加载占位）
   ├─ 作品卡片列表
   ├─ 下拉刷新
   ├─ 上拉无限加载
   └─ 底部状态：加载中/无更多/加载失败
└─ 底部全局导航
二、Tab 标签详细规则
2.1 Tab 基础属性
表格
Tab 标识	名称	访问权限	排序逻辑
hot	最热	全部用户可访问	全平台作品，综合热度分 = 点赞数0.6 + 收藏数0.4，降序排列；支持限定近 7 日 / 近 30 日热门
recommend	推荐	登录后生效；未登录自动切到最热	基于用户行为画像：
1. 已点赞、已收藏作品的标签、标题关键词、风格；
2. 协同过滤，推送同偏好用户喜爱的作品；
3. 剔除已浏览、已点赞收藏重复内容
mine	我的	必须登录，未登录弹出登录弹窗	仅当前登录账号发布的作品，默认按发布时间新→旧排序；附带编辑、下架、删除管理按钮
2.2 Tab 交互逻辑
切换 Tab 清空原有列表、重置页码、重新请求对应接口；
Tab 栏页面向上滚动触达顶部时固定吸顶；
记录当前选中 Tab，页面刷新后自动恢复上次选中状态；
未登录点击「推荐 / 我的」：弹窗引导登录，登录成功后自动切入对应 Tab。

3.1 卡片布局结构

3.2 卡片交互

点击点赞图标：立即提交点赞接口，本地数字 + 1，二次点击取消；
点击收藏图标：收藏 / 取消收藏；
PC 悬浮：卡片轻微上浮 + 阴影加深；移动端点击按压缩放反馈；
「我的」Tab 内卡片：右下角悬浮【编辑】【删除】快捷操作按钮。
四、接口设计规范
4.1 公共基础入参
plaintext
GET /api/work/list
请求头：token（登录态）
入参公共字段：
tab: hot/recommend/mine
page: 页码，默认1
pageSize: 15
1）tab=hot 最热
额外参数：timeRange 可选 7d/30d/all
后端计算：score = likeCount * 0.6 + collectCount * 0.4，按 score 降序
2）tab=recommend 个性化推荐
必须携带有效 token；
后端读取该用户历史点赞、收藏作品的标签、标题分词，匹配库内相似作品推送；
自动过滤已点赞、已收藏、已拉黑作者内容。
3）tab=mine 我的作品
仅校验登录用户身份，筛选userId=当前登录人；
默认按发布时间 createTime 倒序；
返回字段额外携带：作品状态（正常 / 审核中 / 已下架）。

5.2 Pinia 状态管理
js
运行
// stores/useHomeWorkStore.js
import { defineStore } from 'pinia'
export const useHomeWorkStore = defineStore('homeWork', {
  state: () => ({
    activeTab: 'hot',       // 当前选中tab hot/recommend/mine
    workList: [],           // 作品列表
    page: 1,
    pageSize: 15,
    loading: false,
    hasMore: true,
    refreshFlag: false
  }),
  actions: {
    // 切换tab，重置列表与分页
    switchTab(tab) {
      this.activeTab = tab
      this.page = 1
      this.workList = []
      this.hasMore = true
    },
    // 追加列表数据
    appendList(arr) {
      this.workList = this.page === 1 ? arr : [...this.workList, ...arr]
    }
  }
})
5.3 Tab 组件 WorkTab.vue 核心逻辑
vue
<template>
  <div class="work-tab" :class="{fixed: isFixed}">
    <div class="tab-item"
         v-for="item in tabList"
         :key="item.key"
         :class="{active: store.activeTab === item.key}"
         @click="handleClick(item.key)"
    >
      {{ item.label }}
    </div>
  </div>
</template>
<script setup>
import { ref } from 'vue'
import { useHomeWorkStore } from '@/stores/useHomeWorkStore'
const store = useHomeWorkStore()
const isFixed = ref(false)
const tabList = [
  { key: 'hot', label: '最热' },
  { key: 'recommend', label: '推荐' },
  { key: 'mine', label: '我的' }
]
// 监听页面滚动，控制吸顶
const handleClick = (key) => {
  // 未登录拦截推荐、我的
  if(['recommend','mine'].includes(key) && !$user.isLogin){
    $openLoginDialog()
    return
  }
  store.switchTab(key)
  // 发起接口请求
}
</script>
六、瀑布流核心适配改动
仅适配作品卡片
布局计算只需要根据封面图片宽高 + 底部固定信息栏高度计算卡片整体高度；
响应式列数不变：
移动端 2 列、平板 3 列、PC 端 4 列；
图片懒加载、可视区域曝光埋点保留；
Tab 切换时重新执行布局重排。
七、三大 Tab 差异化处理方案
7.1 最热 Tab
后端定时计算热度分值，缓存榜单，减少实时计算压力；
前端仅负责接收排好序的列表，前端无需参与打分排序；
支持增加筛选项：全部 / 近 7 天热门。
7.2 个性化推荐 Tab
后端实现思路
采集用户行为库：用户点赞、收藏作品的tags标签、标题分词；
构建标签权重：用户高频互动标签权重拉高；
检索数据库内带有同类标签、标题语义相似的作品；
去重：过滤已点赞、已收藏、3 天内已曝光内容；
冷处理：新用户无行为数据时自动降级展示最热列表。
前端配合
前端无需做算法处理，仅透传 token，由后端返回推荐结果。
7.3 我的作品 Tab
登录鉴权前置校验，未登录拦截；
卡片增加管理操作：编辑作品、下架、删除；
空状态：「你还没有发布作品，快去上传你的拼豆成品吧」+ 跳转发布页按钮；
展示作品审核状态标签：审核中、已下架。
八、异常兜底状态
未登录访问推荐 / 我的：弹出登录弹窗；
我的作品为空：空页面引导发布作品；
推荐无匹配内容：自动降级加载最热作品；
接口请求失败：底部展示「加载失败，点击重试」；
图片加载失败：统一灰色图片占位图，不破坏瀑布流布局；
切换 Tab 时防抖，取消上一个未完成的接口请求，防止数据错乱。
九、交互体验优化
下拉刷新：任意 Tab 下拉均可刷新当前分类数据；
上拉加载触底距离 200px 提前预加载；
点赞、收藏操作本地即时更新，等待接口回调失败后回滚状态；
页面记住用户上次浏览的 Tab，本地缓存 localStorage 存储 activeTab；
滚动到顶部悬浮「回到顶部」按钮。
十、性能优化要点
海量作品开启虚拟滚动，只渲染可视区域 DOM；
封面图按需裁剪，不同端下发对应尺寸图片（webp 格式）；
Tab 切换时上一页接口 abort 取消请求；
resize 窗口布局计算添加防抖，避免频繁重排；
IntersectionObserver 实现图片懒加载与卡片曝光统计。
十一、测试验收要点
切换三个 Tab 数据互不干扰，列表不会错乱叠加；
最热排序点赞收藏越高越靠前；
登录后推荐内容贴合用户历史收藏点赞风格；
我的作品只展示本人发布内容，管理按钮仅当前账号可见；
未登录限制推荐、我的 Tab；
瀑布流布局无重叠、错位，窗口缩放自适应重排。
