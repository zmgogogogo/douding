1. 业务整体总架构（核心闭环）
1.1 豆仓解决的用户痛点
- 用户不知道自己有多少豆子、缺多少豆子、什么颜色不够
- 手工制作无法统计消耗，重复买料、浪费、缺料翻车
- 做完图纸不知道消耗多少、剩余多少
- 无法快速生成补货清单
- 没有资产记录，不知道豆子花在哪、得在哪
1.2 完整业务闭环（100%闭环）
用户获得豆子（签到/任务/购买/活动）→ 入库流水 → 豆仓库存增加
用户制作图纸完成 → 自动扣料（带损耗）→ 库存减少 → 消耗流水记录
库存低于预警值 → 紧张标色提醒
库存=0 → 缺货红色提醒 + 进入缺货清单
用户手动增删库存 → 实时记录流水
用户查看缺料清单 → 一键补货
1.3 系统核心能力
- 全色系库存管理（系统所有颜色全覆盖）
- 单颜色独立预警阈值
- 自动制作扣料（支持损耗率）
- 库存状态智能判断（充足/紧张/缺货/未拥有）
- 完整出入库流水台账
- 一键缺料清单生成（补货清单）
- 批量补货、批量入库
- 搜索筛选、分类筛选、状态筛选
- 数据缓存、防重复提交、异常回滚

3. 数据字典（全局固定、全项目统一）
3.1 系统全局颜色库（固定不变）
所有颜色由后端统一维护，前端禁止写死颜色
单条颜色固定字段：
- colorId：颜色唯一ID（int）
- colorCode：色号（M01/M02/P01 行业标准）
- colorName：颜色中文名
- colorHex：色值 #xxxxxx
- type：色系分类（马卡龙/纯色/珠光/磨砂/透明/金属）
- sort：排序权重
3.2 用户库存字段（每条用户库存）
- stockNum：当前库存数量（颗）
- warnNum：预警阈值（默认50）
- status：实时计算状态（前端不存，实时算）
- updateTime：最后变动时间
3.3 库存状态 4 种（严格规则）
规则 1：充足 — stockNum > warnNum
规则 2：紧张 — 0 < stockNum ≤ warnNum
规则 3：缺货 — stockNum == 0
规则 4：未拥有 — 用户从未创建该库存记录
UI 颜色规范：
- 充足：绿色 #00b42a
- 紧张：橙色 #ff7d00
- 缺货：红色 #f53f3f
- 未拥有：灰色 #cccccc

4. 顶部数据总览模块（精准计算规则）
三个数据全部实时计算、缓存更新
1. 总豆子数量：用户所有颜色 stockNum 总和
2. 已拥有颜色数：stockNum > 0 的颜色总数
3. 当前缺货数：stockNum == 0 的颜色总数

5. 功能区三大核心按钮（细节逻辑）
5.1 缺料清单（重磅功能）
统计范围：缺货 + 库存紧张全部颜色
每条清单包含：色号、颜色名、当前库存、建议补货量
建议补货量规则：
- 缺货：建议补 100颗
- 紧张：建议补 预警值 - 当前库存
支持功能：
- 一键复制文本清单
- 一键生成图片清单
- 一键跳转采购（如有商城）
5.2 库存流水记录
所有库存变动永久记录、不可删除
流水类型枚举：
- 1 = 手动增减库存
- 2 = 制作图纸自动扣料
每条流水必带：变动前、变动后、变动数量、时间、关联图纸ID（如有）
5.3 批量添加豆子
弹窗多选颜色，统一输入数量批量入库
用于：新手整套入库、大批量补货

10. 制作自动扣料核心业务（最关键闭环）
10.1 扣料触发时机
用户在拼豆制作模式完成图纸、点击完成制作后自动触发
10.2 扣料计算规则
- 基础扣料 = 图纸每种颜色所需数量
- 默认损耗率：5%（用户可手动关闭/修改）
- 最终扣料 = 基础数量 * (1 + 损耗率)
- 小数向上取整（材料不能零点几颗）
10.3 库存不足容错规则（非常重要）
禁止扣成负数
剩余库存 ≥ 需要数量：全额扣除
剩余库存 < 需要数量：全部扣空，库存置0，生成缺料记录
10.4 扣料后联动行为
- 写入库存流水（关联图纸ID）
- 更新豆仓实时库存
- 低于预警值自动变紧张
- 扣空自动变红缺货
- 弹窗提示：本次消耗 + 缺料提示（如有）
10.5 全局开关
底部设置：开启/关闭「制作自动扣料」
关闭后：制作完成不扣任何豆子
