拼豆社区 - 作品详情页全套开发说明书
文档概述
1.1 文档目的
标准化拼豆作品详情页前后端整体开发规范、页面结构、交互逻辑、数据库设计、接口定义、异常处理、兼容适配、上线验收标准，支撑前端、后端、测试、UI 协同开发。
1.2 项目定位
拼豆爱好者社区，本页面展示用户上传像素拼豆图纸、用料清单、参数、社交互动（点赞、评论、关注作者、收藏、下载图纸）核心页面。
1.3 技术栈约定
表格
端	技术选型
前端	Vue3 + TypeScript + Element Plus；移动端采用自适应布局，uniapp 可选做小程序端
后端	Java SpringBoot / Node.js Express；MySQL 8.0；Redis 缓存点赞、浏览量、库存；MinIO 存储图片资源
数据库	MySQL 8.0，Redis 做热点数据缓存
存储	MinIO：作品封面图、高清图纸预览图、用户头像
部署	Nginx 反向代理，HTTPS，CDN 加速静态资源

第六部分：前端异常处理 & 问题兜底方案
6.1 JS 报错捕获
针对你之前遇到报错：Cannot read properties of undefined (reading 'replace')
报错根因
代码中对一个undefined变量调用.replace()字符串方法。
全局规避规范
所有字符串处理前做空值判断
javascript
运行
//错误写法
data.content.replace(/xxx/g,'')
//正确写法
const str = data?.content ?? ''
str.replace(/xxx/g,'')
全局添加window.onerror捕获页面 JS 异常，上报日志后台。
6.2 网络异常
接口 404/500 / 超时：页面展示友好提示「加载失败，请稍后重试」，提供刷新按钮。
6.3 权限异常
401 未登录：统一跳转登录弹窗；403 无权限（未点赞下载图纸）弹窗提示先点赞解锁。
6.4 图片资源异常
图片地址失效自动替换全局默认作品占位图。

第八部分：安全校验规则
XSS 防护：前端渲染评论、用户文案前转义特殊字符，后端过滤危险标签
SQL 注入：后端使用参数化查询，禁止拼接 SQL
接口防刷：点赞、评论、关注设置频率限制，单账号 1 分钟最多 5 次请求
敏感词过滤：评论、作品标题、文案接入敏感词库，命中直接拒绝提交并提示
图片校验：上传图片校验格式、大小、防盗链，禁止违规图片
