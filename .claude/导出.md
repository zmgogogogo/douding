拼豆软件「作品图纸导出」全内容详细开发设计文档
一、整体概述
1.1 业务定位
基于平台已保存的拼豆网格像素数据，对外输出可直接打印施工、备货采购、二次编辑、离线查看的标准化图纸文件；绑定前置权限：仅对已点赞该作品的用户开放下载，未点赞拦截导出接口。
1.2 支持导出格式全集
PDF（主推打印版，核心格式）
PNG 高清图片（预览、手机对照）
Excel/CSV（物料采购、库存核对、表格统计）
SVG 矢量图（设计二次加工、切割机排版）
工程 JSON 源文件（平台内部回传编辑、云端存档）
1.3 前置基础数据来源
作品 ID、画布宽 × 高网格尺寸、每个坐标格子对应的品牌色号、RGB 色值、全量像素点位、作者备注、制作参数、豆子用量统计数据。
二、统一导出数据包整体结构（打包 ZIP 完整版）
用户选择「打包全部文件」时，后端打包压缩包目录结构：
plaintext
拼豆作品_作品ID_作品标题.zip
├─ 01_打印施工图纸.pdf
├─ 02_高清预览图.png
├─ 03_物料采购清单.xlsx
├─ 04_纯数据导出.csv
├─ 05_矢量图纸.svg
├─ 06_工程源文件.json
└─ readme.txt（制作须知、参数说明）
三、每种文件内部完整内容拆解
（一）PDF 可打印施工图纸（最重要，分多页结构化排版）
第 1 页：封面总览页
头部基础作品信息区
作品标题、作者昵称、作者 UID、作品唯一 ID
基础工艺参数：画布尺寸（W×H 格）、成品物理尺寸、难度等级、预估制作时长
选用拼豆品牌：MARD/Artkal/Perler 等色系版本
版权标注：原创 / 二创标记、转载授权说明
全局数据汇总卡片
总使用颜色种类数量、拼豆总颗数
建议预留损耗：整体 + 5%~10% 备用豆子
缩略效果图：无网格纯彩色成品预览小图
页面底部：打印适配提示（A4 横向打印、缩放适配、无需自适应拉伸）
第 2 页：色号图例对照表（施工必备）
表格形式固定布局：
表格
色块预览	品牌色号	颜色中文名称	RGB 十六进制	所需颗数	建议备货量（含 5% 损耗）
彩色小方块	G15、A08 等	米白、正红、浅蓝	#f9f2e0	3361	3530
额外配置：
每一行色块与文字一一对应，打印后可裁剪下来贴在收纳盒分类
颜色按用量从多到少自动排序；高亮标注用量 Top3 主力色
全局色标校准条（CMYK 印刷基准），避免打印偏色
第 3~N 页：主体网格施工图纸（核心拼装页）
坐标轴体系
横向列：A、B、C、D…… 字母编号；纵向行：1、2、3、4…… 数字编号，定位格式A1、C12
每 5 格、10 格加粗加深网格线，方便快速计数定位，防止拼错行列
网格单格内印刷对应豆子色号简写，字体自适应格子大小；深色底色用白色字体，浅色底色黑色字体
两种可选模式（导出前用户勾选切换）
模式 1：彩色网格版：格子填充对应实际颜色 + 中间印色号；直观对照
模式 2：黑白线稿版：仅黑色网格线条 + 格子内色号，节约打印墨水，支持用户手动涂色标记进度
大图自动分页切割逻辑
画布＞60×60 标准拼豆板时，自动切分为多张 A4 页面；每张页面标注：页码、所属行列区间、拼接对齐指引箭头、拼接顺序示意图
页面页脚：当前页行列范围、作品水印（轻量化平台标识，不遮挡施工区域）
最后一页：制作指引与补充说明
推荐拼装顺序（从中心向外 / 从上至下分区拼装）
易混淆相近色区分提示、热熔熨烫建议温度与时间
空白备注栏，可供手写记录制作进度
库存自检入口提示（跳转平台豆子库存核对）
（二）PNG 高清图片图纸（移动端对照、社交分享）
可选缩放档位：1×/2×/3 倍放大
推荐 2 倍（单格 20×20 像素，A4 打印单格约 1.8mm，肉眼清晰）
完整布局：顶部作品基础信息 + 带坐标网格主体图 + 右下角迷你色号图例
两种可选样式：
完整版：网格 + 坐标 + 格子内色号 + 侧边用料统计
纯效果图：无网格、无文字标注，仅成品彩色像素预览图
图片属性：无压缩无损 PNG、透明背景可选（空白格子透明）、分辨率固定、不带多余水印
（三）Excel 表格文件（备货、库存管理、线下教学）
内置 3 个独立工作表 Sheet：
Sheet1：网格坐标施工图
表格单元格一一对应拼豆网格，单元格填充对应颜色底色，单元格内写入对应色号
顶部行号、左侧列号锁定冻结，滚动查看坐标不丢失
页面布局预设 A4 横向打印格式，一键直接打印
Sheet2：色号物料汇总表
标准统计字段：
品牌、色号、颜色名称、RGB、实际需求数量、5% 损耗预估总数、现有库存缺口、采购数量、单包规格、预估需要购买包数、颜色占整体比例
Sheet3：全点位坐标明细表
逐条结构化数据：行号、列号、色号、颜色RGB，适合批量核对、精准定位某一格颜色，适合精细化教学、接单验收核对
（四）CSV 纯数据清单（轻量化导入购物车、库存系统）
纯文本结构化字段，可直接复制导入电商购物车、本地表格：
colorCode,colorName,hexRgb,needCount,suggestCount,brandSeries
示例：
G15, 奶白色，#f9f2e0,3361,3530,MARD221 色
（五）SVG 矢量图纸（无损二次设计）
矢量网格路径，无限放大不失真；每个格子为独立矢量矩形色块
内置图层分层：网格线图层、填充色块图层、文字色号图层、坐标标注图层
可导入 AI、Inkscape、激光切割排版软件，用于定制底板印刷、机器自动排版加工

（七）附带说明文档 readme.txt
文件各类型用途介绍

豆子损耗建议、熨烫注意事项
版权声明、禁止商用盗用提示、平台二次上传规则
四、导出前用户可自定义配置项（前端交互选项）
纸张规格：A4 横向 / A4 纵向、自定义尺寸
图纸显示开关：网格线、行列坐标、格子内色号、图例、统计数据
图纸模式：彩色打印版 / 黑白省墨版
损耗比例：0%/5%/10% 备货余量

选择拼豆品牌色库（切换不同厂商对应色号映射）
是否添加轻量化水印、自定义备注文字嵌入图纸
五、后端业务逻辑、权限与缓存规则
5.1 权限校验（核心拦截）
登录态校验：未登录跳转登录弹窗
点赞校验：当前用户未对该作品点赞，返回 403 禁止导出，弹窗提示「点赞解锁图纸下载」
限流控制：单账号 1 分钟最多 3 次导出，防止恶意高频刷文件
作品状态校验：下架、删除、封禁作品禁止导出
5.2 数据处理流程
读取 Redis 缓存内该作品网格数据、用量统计，减少 MySQL 查询
后端服务生成 PDF/Excel 文件，临时存放对象存储 MinIO，设置短期有效期（2 小时）
用户下载后自动清理临时文件；大尺寸图纸异步生成，前端展示生成进度条
下载记录入库：记录用户 UID、作品 ID、下载时间、导出格式，用于数据统计
5.3 库存联动特色功能（嵌入导出清单）
用户已绑定个人豆子仓库时，导出清单自动附加：
现有库存数量、缺口数量、需要单独采购的色号精简清单，直接生成补货表
六、前端交互完整流程
作品详情页「下载图纸」按钮
弹出配置弹窗，勾选导出格式、打印参数、损耗比例
点击确认→前端校验登录 + 点赞状态
合法则发起后端生成任务，展示加载动画「图纸生成中」
生成完毕：弹窗提供单文件下载 / 一键下载 ZIP 压缩包
下载记录存入个人中心「我的下载」列表
七、异常兜底处理
画布尺寸过大（＞200×200）：提示分批次导出，避免文件过大生成超时
临时文件生成失败：提示重试，后端重新渲染
网络中断：支持断点续下载
空白无有效像素作品：禁止导出，提示作品无有效图案
图片打印色块偏色：PDF 内置色彩校准配置，适配主流打印机
