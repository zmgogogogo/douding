一、产品概述
1.1 核心痛点与解决价值
手工拼豆制作过程中，用户普遍面临四大痛点，拼豆模式针对性解决：
表格
用户痛点	拼豆模式解决方案
数格子困难，容易数错行、错列，成品偏移	十字定位线 + 坐标标注 + 高亮引导，像素级精准定位
找色麻烦，频繁对照色卡，容易拿错色号	当前颜色高亮放大，色号醒目显示，色板实时对照
大图纸容易漏拼、重复拼，进度混乱	分步高亮引导，已拼区域自动标记，进度实时保存
无法统计用量，不知道库存够不够	实时显示单种颜色用量、累计进度、剩余数量，联动豆仓库存校验
1.2 适用场景
新手入门：零基础用户跟着分步引导，按颜色依次填充，零门槛完成制作
大幅图纸：几百 × 几百格的大尺寸图纸，分区域 / 分颜色逐步推进，避免混乱
精细复杂图：人像、动漫等细节丰富的图纸，精准定位五官、线条等细节
批量制作：工作室 / 玩家重复制作同款，计数与进度管理，统计产能
教学演示：博主 / 老师分步展示制作过程，生成教程动图
1.3 用户分层适配
表格
用户类型	核心需求	适配模式
新手用户	引导清晰、操作简单、不易出错	按色分步模式 + 高亮引导 + 操作提示
进阶用户	高效定位、快速找色、进度可控	全局浏览模式 + 单色调高亮 + 快捷切换
重度 / 工作室	批量制作、计数统计、多图纸管理	批量制作模式 + 计数统计 + 库存联动
1.4 设计核心原则
视觉优先原则：色块大、色号醒目、对比强烈，长时间制作不费眼，支持深色护眼模式
极简操作原则：制作过程中单手可操作，大按钮、手势快捷操作，避免精细点击
精准对齐原则：网格与像素严格对齐，无偏移、无模糊，保证实体制作与图纸 1:1 对应
离线可用原则：加载完成后可断网使用，进度本地缓存，不依赖网络
进度可溯原则：自动保存制作进度，退出再进入可无缝继续，支持多进度存档
全链路联动原则：联动图纸数据、豆仓库存、制作记录，完成后自动扣减库存、生成功绩

四、三大核心制作模式详细设计
4.1 全局浏览模式
定位
适合有经验的用户，完整显示整张图纸，自主对照制作，提供辅助定位工具，不做分步强制引导。
核心功能
完整图纸显示：全色完整显示图纸，可自由缩放平移
单色高亮：点击色板中任意颜色，该颜色高亮显示，其余颜色变暗，快速定位所有同色豆子位置
网格与坐标：可开关显示网格线、行列坐标，方便数格
色号标注：可开关显示每个色块的色号文字，适合对照色板找豆
标记已完成：手动勾选已完成的颜色，对应颜色变灰，直观展示进度
交互逻辑
点击右侧色板中的颜色，画布即时高亮对应色块
再次点击取消高亮，恢复全色显示
支持同时高亮多种颜色
缩放平移操作与编辑器一致，保持操作习惯统一
4.2 分步制作模式（核心模式）
定位
产品核心功能，按一定规则将图纸拆分为多个步骤，用户逐步骤完成，每一步只高亮当前需要拼的豆子，其余区域弱化，专注高效，零门槛。
4.2.1 三种分步方式
方式一：按颜色分步（最常用・默认）
拆分规则：一种颜色为一个步骤，按颜色用量从多到少排序，也可自定义顺序
适用场景：绝大多数拼豆制作，同色豆子一起拼，效率最高
每步内容：单种颜色的所有豆子高亮，显示色号、总数量、已拼数量、剩余数量
方式二：按区域分步
拆分规则：将图纸等分为若干区块（如 2×2、3×3、4×4），一个区块为一个步骤
适用场景：超大尺寸图纸，分块推进，避免全局浏览眼花缭乱
每步内容：当前区块内所有颜色完整显示，其余区域变暗，可配合单色高亮使用
方式三：按图层分步
拆分规则：按照图纸的图层顺序，一个图层为一个步骤
适用场景：分层设计的复杂图纸，先拼底层再拼上层，符合制作逻辑
依赖：需要图纸带有图层信息，扁平图纸自动生成分层
4.2.2 分步高亮渲染规则
高亮区：当前步骤的豆子，100% 不透明度，正常颜色显示，边缘可加发光效果增强辨识度
已完成区：已拼完的步骤，降低不透明度至 40%，或变为灰度，直观区分已做 / 未做
未开始区：后续步骤的豆子，降低不透明度至 20%，隐约可见轮廓，不干扰当前操作
可自定义：高亮强度、已完成 / 未完成透明度可在设置中调节
4.2.3 步骤控制
基础操作：上一步、下一步、跳转到指定步骤
自动播放：自动按顺序切换步骤，间隔时间可设置（3s/5s/10s），适合演示、录教程
快速跳转：点击进度条、展开步骤列表，可直接跳转到任意颜色 / 步骤
标记完成：当前步骤拼完后，点击「完成本步」，自动标记并进入下一步
撤销标记：可回退上一步，取消已完成标记
4.2.4 进度保存机制
自动保存：每完成一步自动保存进度到本地，同时同步云端（登录状态下）
实时保存：手动标记、跳转步骤实时保存，退出页面不丢失
多存档：同一张图纸支持多个存档，比如「版一正常做」「版二改色做」
进度同步：多端登录同一账号，制作进度实时同步，手机做一半平板接着做
4.3 AR 实景辅助模式（进阶功能）
定位
利用手机摄像头，将虚拟图纸精准叠加到实体拼豆板上，实时高亮提示下一颗豆子的位置，实现「对着板子直接拼」的沉浸式体验。
核心功能
模板识别：摄像头对准拼豆模板，自动识别模板边框与网格，校准对齐
虚拟叠加：将图纸像素 1:1 叠加到实体模板上，半透明显示
实时高亮：当前步骤的豆子高亮闪烁，提示摆放位置
错误检测：自动识别已摆放的豆子颜色，放错时红色提示纠正
自动推进：识别到当前颜色全部摆放完成，自动进入下一步
技术实现逻辑
图像识别：检测拼豆板的矩形边框、网格角点，计算透视变换矩阵
坐标映射：将虚拟图纸坐标映射到摄像头画面坐标，实现 1:1 对齐
颜色识别：通过图像识别判断已摆放豆子的颜色，校验正误
实时渲染：将虚拟高亮层叠加到摄像头画面上，30 帧 / 秒流畅刷新
适用终端
仅限移动端 APP / 小程序，依赖摄像头权限，PC 端不提供该模式。

六、进度管理与制作闭环
6.1 进度存储机制
本地存储
使用 localStorage / 本地数据库存储制作进度，离线可用
存储内容：图纸 ID、当前步骤、已完成步骤列表、存档时间、累计时长
自动保存间隔：每次步骤变更立即保存，最多保留最近 20 条历史进度
云端同步
登录用户自动同步进度到服务端，多端一致
冲突处理：以最新修改的进度为准，提示用户选择保留版本
历史版本：保留最近 10 次进度快照，可回退到任意版本
6.2 多存档管理
同一张图纸可创建多个独立存档，命名区分
存档操作：新建存档、重命名、删除、切换
适用场景：同款图纸做多个颜色版本、多人共用一个账号制作
6.3 制作完成闭环
完成触发
用户拼完最后一步，点击「完成制作」按钮，触发完成流程：
完成确认弹窗：显示成品预览、总豆子数、总颜色数、制作时长
豆仓扣减：
自动按图纸用量扣减用户豆仓对应颜色的库存
支持设置损耗率（默认 5%），实际扣减 = 图纸用量 × (1 + 损耗率)
库存不足提示，可选择部分扣减或取消
生成制作记录：保存到「我的制作」，包含图纸、时间、时长、完成状态
后续引导：
「发布成品」：拍照上传成品，发布到作品社区
「再来一个」：返回模板库，选择新图纸
「生成教程」：自动生成分步制作教程图
6.4 制作统计
个人中心「制作数据」：累计制作图纸数、总豆子数、总制作时长、连续制作天数
单图纸统计：每次制作的时长、用量、完成时间
周 / 月报表：制作趋势、颜色消耗排行，辅助用户规划采购
七、前端技术实现（Vue 3 + Canvas）
7.1 渲染架构
采用分层 Canvas 渲染架构，保证缩放平移流畅、高亮切换无卡顿。
表格
画布层级	内容	重绘时机
背景层	画布底色、基础网格线	缩放、平移、网格设置变更
底图层	完整图纸灰度 / 低透明度底图	切换图纸、尺寸变更
高亮层	当前步骤高亮的色块	切换步骤、颜色变更
已完成层	已完成步骤的半透明色块	标记完成 / 撤销
辅助层	十字线、坐标、放大镜、选区	鼠标 / 触摸移动、设置变更
渲染核心优势
静态层一次绘制缓存，视图变换仅做矩阵变换，不重绘像素
步骤切换仅重绘高亮层与已完成层，底图不动，切换速度＜10ms
大尺寸图纸（500×500 以上）也能保证 60 帧流畅操作
7.2 核心算法
7.2.1 分步数据生成算法
按颜色分步：
遍历图纸像素矩阵，统计每种颜色的所有坐标点
按颜色数量从多到少排序，生成步骤列表
每个步骤包含：颜色 ID、色号、数量、坐标点数组
按区域分步：
根据行列数均匀划分区块，计算每个区块的像素范围
提取每个区块内的所有像素，生成步骤数据
按图层分步：
读取图纸图层数据，按图层顺序生成步骤
无图层图纸自动按颜色深浅分层
7.2.2 高亮渲染算法
预先生成全色底图纹理
高亮层使用离屏 Canvas，只绘制当前步骤的像素点
已完成层单独绘制，设置全局透明度
最终多层叠加合成，使用全局合成模式控制显示效果
7.2.3 坐标映射算法
维护视图变换矩阵：平移量 + 缩放比例 + 旋转角度
屏幕坐标转画布坐标：用于触摸点定位、十字线计算
画布坐标转屏幕坐标：用于绘制高亮像素、网格线
7.3 性能优化策略
离屏缓存：底图、网格层预渲染为离屏 Canvas，平移缩放直接贴图，零计算
脏矩形渲染：局部变更只重绘影响区域，不全量刷新
视口裁剪：放大时只渲染可视区域内的像素，超出视口部分不绘制
数据预加载：进入制作模式前预先生成分步数据，切换步骤无延迟
Web Worker：大数据量分步计算放入 Worker，不阻塞主线程 UI
像素复用：相同颜色批量绘制，减少绘制调用次数

十、异常与边界处理
10.1 加载异常
图纸加载失败：显示错误提示，提供重试按钮，返回上一页
大图纸加载慢：显示加载进度条，提示「大图纸加载中，请稍候」
分步数据生成失败：降级为全局浏览模式，提示「分步加载失败，已切换为浏览模式」
10.2 进度异常
进度冲突：多端修改同一进度，提示用户选择「保留本地」或「同步云端」
进度损坏：检测到进度数据损坏，自动恢复到上一个有效版本
离线保存：无网络时进度保存在本地，联网后自动同步云端
10.3 操作边界
第一步 / 最后一步：上一步 / 下一步按钮置灰，不可点击
缩放边界：最小缩放 5%，最大缩放 1600%，防止过度缩放
平移边界：限制平移范围，图纸不超出屏幕太远
10.4 性能边界
超大幅图纸（＞1000×1000）自动降级：关闭部分特效、降低渲染精度
低端设备自动开启性能模式：减少动画、简化效果，保证流畅度
长时间使用提示休息，护眼提醒
