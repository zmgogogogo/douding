# 导出功能重构方案

## 一、参考分析：dmao.cloud 导出页面

### 1.1 整体架构

dmao.cloud 使用**独立全屏导出页面**（路由 `/export`），核心设计理念：

- **所见即所得** — 左侧实时预览，右侧配置面板，任何参数变更即时刷新预览
- **前端 Canvas 渲染** — 在浏览器端用 Canvas 生成高清预览图，后端不参与渲染
- **纯 PNG 导出** — 只导出 PNG 图片，不生成 PDF/SVG/CSV 等多格式文件

### 1.2 功能模块拆解

```
┌──────────────────────────────────────────────────────┐
│  顶部导航栏                                           │
│  [返回] 作品名称    [分辨率: 1K|2K|4K|8K]             │
├──────────────────────┬───────────────────────────────┤
│                      │  辅助线 ▾                     │
│   实时预览区          │  ├ 无 / 每5格 / 每10格 / 自定义 │
│   (Canvas)           │  ├ 网格颜色 + 透明度            │
│                      │  ├ 网格线宽                     │
│   - 像素完美渲染      │  ├ 加粗线颜色 + 透明度          │
│   - 支持缩放拖拽      │  ├ 加粗线间隔                   │
│   - 点击可全屏预览    │                                │
│                      │  叠加层 ▾                      │
│                      │  ├ 显示网格线 ✓                 │
│                      │  ├ 显示色号 ✓                   │
│                      │  ├ 显示用料清单                  │
│                      │  └ 显示边框(行列号)             │
│                      │                                │
│                      │  水印 ▾                        │
│                      │  ├ 文字内容 + 颜色 + 透明度     │
│                      │  └ 位置                         │
│                      │                                │
│                      │  用料清单 ▾                     │
```

### 1.3 Canvas 渲染管线（dmao 方案）

```
grid_data + color_map
       │
       ▼
┌─────────────────────┐
│ 1. 背景填充 #ffffff  │
├─────────────────────┤
│ 2. 棋盘格背景        │  ← 半透明格子，辅助辨认空/白色
├─────────────────────┤
│ 3. 逐格色块填充      │  ← pixelData → fillRect
├─────────────────────┤
│ 4. 细网格线          │  ← 普通格线，rgba 半透明
├─────────────────────┤
│ 5. 加粗网格线        │  ← 5/10 格加粗线
├─────────────────────┤
│ 6. 色号文字标注      │  ← 亮度自适应黑/白文字
├─────────────────────┤
│ 7. 边框 + 行列号     │  ← 四边标注行列数字
├─────────────────────┤
│ 8. 顶部标题栏        │  ← 渐变背景 + logo + 标题
├─────────────────────┤
│ 9. 水印文字          │  ← 底部 @作者名
├─────────────────────┤
│10. 用料清单 (可选)    │  ← 底部色号列表
└─────────────────────┘
       │
       ▼
  canvas.toBlob() → PNG 下载
```

### 1.4 核心技术要点

| 功能 | 实现方式 |
|------|---------|
| 实时预览 | 前端 Canvas 2D，每次参数变更重绘 |
| 分辨率控制 | 调整 `cellSize` 倍数（分辨率越高格子越大） |
| 棋盘格背景 | 交替填充 `rgba(220,220,228,0.28)` 半透明格 |
| 色号文字亮度自适应 | `luminance = 0.2126*R + 0.7152*G + 0.0722*B`，>0.4 用黑，否则用白 |
| 导出触发 | `canvas.toBlob('image/png', 1)` 最高质量 |
| 水印 | 底部居中文字，可调颜色/透明度 |
| 用料清单 | 从 `colorMap` 统计每种颜色的使用次数，支持排序 |

## 二、当前豆丁导出系统现状

### 2.1 当前导出流程

```
编辑器/详情页 → 点击导出按钮 → 直接调后端API → 后端生成文件 → 返回下载
```

**问题**：
1. 无预览 — 用户不知道导出结果长什么样
2. 无配置 — 无法调整网格线、色号标注、边框等
3. 后端渲染 — PDF/PNG 都在后端生成，增加服务器压力
4. 格式过多 — PDF 含封面/图例/指引等冗余页面

### 2.2 当前后端导出接口

| 路由 | 格式 | 说明 |
|------|------|------|
| POST /api/export/png/:id | PNG | 后端 Sharp 渲染高清 PNG |
| POST /api/export/pdf/:id | PDF | PDFKit 生成（刚精简为纯施工图） |
| POST /api/export/svg/:id | SVG | SVG 矢量 |
| POST /api/export/json/:id | JSON | 纯数据 |
| POST /api/export/csv/:id | CSV | 色号矩阵 |
| POST /api/export/zip/:id | ZIP | 多格式打包 |
| POST /api/export/grid | PNG | 直接传 grid 数据渲染 PNG |
| POST /api/export/pdf | PDF | 直接传 grid 数据渲染 PDF |

### 2.3 当前前端触发点

- `EditorTopBar.vue` — 编辑器顶部导出按钮
- `DetailView.vue` — 作品详情页下载按钮
- 均直接调 API，无预览页面

## 三、重构目标

### 3.1 核心目标

将导出从"盲操作 API 调用"改为"**可视化配置 + 实时预览 + 一键下载**"的独立导出页面。

### 3.2 设计原则

1. **前端渲染为主** — Canvas 2D 在浏览器端完成所有渲染，减轻服务器压力
2. **所见即所得** — 预览即最终效果，零意外
3. **配置即时生效** — 切换开关/调整参数 → 预览立刻更新
4. **渐进增强** — 先实现核心 PNG 导出，再逐步丰富配置项
5. **移动端友好** — 竖屏时上下分栏（上预览/下配置），横屏/桌面端左右分栏

### 第二步：Canvas 预览核心渲染

**文件**：`src/views/ExportView.vue`（composables 可拆分）

**渲染步骤**：
1. 白色背景
2. 棋盘格背景（空/白色格子的辅助辨认）
3. 逐格填充色块
4. 细网格线（半透明）
5. 加粗网格线（每 N 格）
6. 色号文字标注（亮度自适应颜色）

**核心状态**：
```js
const gridWidth = ref(32)
const gridHeight = ref(32)
const gridData = ref([])       // 一维数组，每个元素是 colorId
const colorMap = ref(new Map()) // colorId → { id, code, hex, name }
const cellSize = ref(16)       // 基础格子像素大小
```

**验收标准**：
- [ ] Canvas 正确渲染珠子色块
- [ ] 棋盘格背景正确显示
- [ ] 网格线正确绘制

### 第三步：分辨率选择

**UI**：顶部导航栏右侧，分段控制器

| 选项 | 目标像素 | 说明 |
|------|---------|------|
| 1K | 1024 | 小图快速预览 |
| 2K | 2048 | 常规导出（默认） |
| 4K | 4096 | 高清打印 |
| 8K | 8192 | 超大尺寸 |

**逻辑**：
```js
const resolutionOptions = [
  { key: '1k', label: '1K', targetPx: 1024 },
  { key: '2k', label: '2K', targetPx: 2048 },
  { key: '4k', label: '4K', targetPx: 4096 },
  { key: '8k', label: '8K', targetPx: 8192 },
]

// 计算 cellSize = targetPx / max(gridWidth, gridHeight)
const cellSize = computed(() => {
  const maxDim = Math.max(gridWidth.value, gridHeight.value)
  const opt = resolutionOptions.find(o => o.key === selectedResolution.value)
  return Math.floor(opt.targetPx / maxDim)
})
```

**验收标准**：
- [ ] 切换分辨率预览同步更新
- [ ] 高分辨率渲染性能可接受（可加 loading）

## 七、与 dmao.cloud 的差异对比

| 维度 | dmao.cloud | 豆丁重构后 |
|------|-----------|-----------|
| 导出格式 | 仅 PNG | PNG 为主，保留 PDF |
| 后端参与 | 无 | 保留后端 PDF 生成（可选） |
| 配置项 | 丰富 | 对齐 dmao |
| 色板来源 | 用户仓库数据 | beads 数据库 |
| 水印 | 支持 | 支持 |
| 用料清单 | 支持 | 支持 |
| 移动端适配 | 良好 | 对齐 |
