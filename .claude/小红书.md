一、产品概述
1.1 核心价值
解决用户「看到小红书好看的拼豆图案→保存图片→打开软件→上传转图」的长链路痛点，实现粘贴链接 → 一键生成拼豆图纸的极简操作，降低创作门槛，提升转图转化率与用户留存。
1.2 核心使用场景
用户在小红书刷到拼豆成品 / 参考图，复制链接回到拼豆软件，直接导入生成图纸
博主分享拼豆教程笔记，粉丝通过链接一键导入同款图纸制作
用户批量收藏的小红书拼豆笔记，批量导入生成自己的图纸库
1.3 设计原则
极简操作原则：粘贴链接自动解析，一键生成，最少两步完成转图
合规前置原则：导入前弹出版权提示，用户确认后再执行，规避版权风险
失败兜底原则：解析失败时给出明确原因，提供手动上传图片的替代方案
复用现有能力原则：图片提取后直接复用现有智能转图引擎，不重复造轮子
内容安全原则：所有提取图片必须经过内容安全审核，违规内容自动拦截
1.4 功能入口
首页「图片转拼豆」入口内，增加「链接导入」Tab
转图页面顶部切换：本地上传 / 链接导入
分享唤起：从小红书分享到 APP 时自动识别链接并进入导入流程

4.2 核心技术策略：双解析策略
为应对小红书反爬限制，采用「官方开放接口优先 + 页面解析兜底」的双策略，保证高可用性。
策略一：开放平台 / 合作接口解析（主路径）
对接小红书开放平台官方接口，通过笔记 ID 获取笔记详情与图片列表
优势：稳定、合规、字段完整、无反爬风险
适用：有官方合作资质的场景
策略二：公开页面信息提取（兜底路径）
请求笔记公开页面，解析 HTML 提取标题、作者、图片列表
优势：无需资质，通用可用
注意：仅提取公开可见信息，模拟正常浏览器请求，控制频率，避免触发反爬
合规：仅用于用户主动提交的单条笔记解析，不做批量爬取

4.7 反爬与风控策略
用户级限流：单用户每分钟最多解析 5 次，每天最多 50 次
IP 级限流：单 IP 每日解析上限，防止批量爬取
请求伪装：兜底解析时使用真实 User-Agent、随机延时，模拟正常用户访问
失败降级：连续失败多次后，暂时禁用该功能，提示用户手动上传
User-Agent 轮换：备用多个浏览器 UA，避免被封禁
代理池（可选）：高并发场景下使用代理 IP 池，降低封禁风险
4.8 降级与重试机制
主解析策略失败自动降级到兜底策略，用户无感知
单次解析失败自动重试 1 次，仍失败才返回错误
图片下载失败重试 2 次，超时时间 5 秒
小红书接口限流时，返回「当前解析人数较多，请稍后重试」，并建议手动上传
五、合规与安全设计
5.1 版权合规设计
前置提示：导入页面显著位置显示版权提示，用户必须勾选确认才能生成
用户协议：用户协议中明确约定，导入内容仅可个人学习使用，禁止商用、禁止二次传播
平台免责：平台仅提供工具，内容版权由用户自行负责，侵权投诉渠道公示
投诉处理：开通版权投诉通道，接到投诉后 24 小时内下架相关内容
禁止批量：严格限制单用户导入频率，禁止批量爬取内容
5.2 内容安全设计
所有提取图片必须审核：未通过内容安全审核的图片，禁止生成图纸
违规拦截：涉黄、涉政、涉暴、敏感内容自动拦截，记录违规用户
人工复审：疑似违规内容进入人工审核队列
违规处罚：多次导入违规内容的用户，禁用导入功能，严重者封禁账号
5.3 数据安全
用户导入的图片仅用于生成图纸，不做他用
原始链接、笔记信息仅保留必要字段，不存储用户隐私数据
操作日志全记录，可追溯可审计

笔记不存在 / 已删除	解析返回 404，标记失败	笔记不存在或已被删除
笔记为私密	解析返回权限错误	该笔记为私密内容，无法导入
触发小红书反爬	降级备用策略，仍失败则提示	当前解析繁忙，请稍后重试或手动上传图片
图片下载失败	重试 2 次，失败则跳过该图	部分图片解析失败，已自动跳过
图片审核不通过	拦截该图，记录违规	图片包含违规内容，无法生成
用户操作频繁	限流拦截	操作过于频繁，请稍后再试
6.3 缓存策略
解析结果缓存：同一笔记 ID 的解析结果缓存 2 小时，重复导入直接返回，减少重复请求
图片缓存：已转存的图片不再重复下载
缓存失效：笔记删除 / 更新时缓存自动失效（通过失败重试更新）
